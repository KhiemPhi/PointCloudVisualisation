Instructions:
    • Double-click on the plot to add a new point
    • The depth slider sets the z-coordinate
    • Click "Delete Selected Point" to remove the selected custom point
    • Use the "Assign to Part" dropdown and click "Assign Selected Point" to reassign the custom point
    • Click two points (loaded or custom) in sequence to draw an arrow between them
    • Select an object and batch from the dropdowns
    • Click on any point to add a directional arrow
    • Choose a direction (+X, -X, +Y, -Y, +Z, -Z) from the popup menu
    • To change the arrow direction, click on another point
    • The arrow represents the axis direction for the screw
    • Select RANSAC Mode from the toggle buttons
    • Once 3 points are selected, clickPlot RANSAC Circleto draw the best-fit circle
    • Starting a new RANSAC segment will clear all visible circles from the plot
    • Select Handle Mode from the toggle buttons
    • Click "Start Drawing Handle" to begin creating a cup handle
    • Click on orange point cloud (top rim) and drag to green point cloud (bottom) to create a C-shaped handle
    • Click "Finish Handle" to complete and save the handle
    • Use "Clear Handle" to remove the current handle being drawn
    • Select existing handles from the dropdown to view them
